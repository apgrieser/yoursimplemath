Quick Printing Blueprint

  • Worksheet Sets: Print in color or select Ink-Saving B&W pages for quick classroom copying. The first three pages of a worksheet set PDF contains color versions, page 4-6 contain the b&W versions, and the last three pages are the answer keys for each level of difficulty.
  • Poster Files: Set printer scaling to "Actual Size" (100%) and orientation to Portrait. Use the file that includes 18"x24" in its name for larger wall displays or choose the file with 8.5"x11" in its filename for student notebook size versions.
  • ZIP Files: Double-click on Mac, or right-click and select Extract All on Windows to access your PDFs.
